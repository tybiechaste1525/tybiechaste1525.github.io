## 📖 What Is FakePlayer-CE?

FakePlayer-CE is a free, community-maintained tool that lets you add **fake players** to your Minecraft server. These fake players can chat, move around, join games, and interact with your world—just like real players, but they're completely automated.

Think of it as adding friendly (or mischievous) ghosts to your server who are always ready to help you test things, populate your world, or make your server feel alive even when no one else is online. Whether you run a small server for friends or a large community, FakePlayer-CE gives you full control over these virtual players with simple commands.

This **Community Edition** (CE) is a continuation of the original FakePlayer plugin, meaning it's actively updated and improved by a team of dedicated volunteers. It's designed to work with modern Minecraft server software like Paper and Purpur.

## 🛠️ How to Use FakePlayer-CE

FakePlayer-CE is controlled through simple commands. You can type these directly into your server console or, if you have operator (OP) permissions, in the in-game chat.

| Command | What It Does |
| :--- | :--- |
| `/fakeplayer spawn <name>` | Creates a fake player with the name you choose. |
| `/fakeplayer remove <name>` | Removes a fake player from the server. |
| `/fakeplayer list` | Shows a list of all active fake players. |
| `/fakeplayer chat <name> <message>` | Makes a specific fake player say a message. |
| `/fakeplayer move <name> <x> <y> <z>` | Makes a fake player walk to a location. |
| `/fakeplayer follow <name> <player>` | Makes a fake player follow a real player around. |

**Example:** To create a fake player named "Steve" and have him say hello, you would type:
1.  `/fakeplayer spawn Steve`
2.  `/fakeplayer chat Steve Hello everyone!`

It's that simple! You can use these commands to create lively scenes, test your mini-games, or just have fun.

## ⚙️ Configuration (For Advanced Users)

For those who want to tweak things further, FakePlayer-CE comes with a `config.yml` file located inside the `plugins/FakePlayer-CE/` folder. You can open this file with any text editor (like Notepad). Here, you can change settings like:

- The maximum number of fake players allowed at once.
- The default prefix for fake player names.
- Whether fake players can take damage or deal damage.
- Permission nodes for different commands.

A lot of these settings are optional—the plugin works great right out of the box!
